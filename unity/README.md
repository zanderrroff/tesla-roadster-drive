# Motor Coast — Unity 6 / iPhone

Нативная игра на Unity **6000.3.26f1 LTS**, URP 17.3, Metal и IL2CPP. Сцена, интерфейс, камеры и WheelCollider работают в Unity; C++ управляет тягой, торможением, безопасным реверсом и сглаживанием руля. В iOS код C# также преобразуется в C++ через IL2CPP. WebView не используется.

На 18 октября 2026 успешно выполнены импорт ресурсов, компиляция Unity, 14 тестов и рендеры на Metal. Облачный Xcode 26.6 / iOS SDK 26.5 собрал ARM64-приложение; подписанная **MotorCoast-2.0.0-1.ipa** размером 75 670 937 байт прошла проверку подписи и профиля. Статус обработки Apple отдельно зафиксирован в `VERIFICATION.txt`. Просмотр в редакторе не является тестом на физическом iPhone.

[Скачать тестовую IPA 2.0.0 (1)](https://github.com/zanderrroff/tesla-roadster-drive/releases/tag/ios-v2.0.0-build-1). Apple завершила обработку (`VALID`); сборка доступна владельцу аккаунта во внутренней группе TestFlight (`IN_BETA_TESTING`). Публичная внешняя бета и выпуск в App Store пока не отправлены на проверку.

## Игра и управление

Семь автомобилей: Tesla Roadster, BMW M3 E30, Mercedes AMG GT, Mercedes 190E EVO, Nissan Skyline C110, Porsche 911 Carrera 4S, Ferrari 458 Italia. Tesla использует присланную модель: 133 574 треугольника в обычном режиме и 344 098 в режиме «Детали». Остальные машины — до 150 000 треугольников. Загружается выбранный автомобиль; остальные выгружаются.

Большая открытая площадка с пятью рампами, слаломом, кругами для дрифта, павильоном и побережьем. Фотограмметрия скал Poly Haven сокращена с 461 824 до 11 998 треугольников, текстуры 2K. Поверхность и коллайдеры рамп используют одну геометрию; дорожная разметка не мешает колёсам.

На телефоне — вращаемый пальцем руль слева, педали справа, отдельные D/R, ручник P, сигнал, камера, сброс и пауза. Графика управления взята из Car Controls (looneybits, CC0), Kenney Mobile Controls (CC0), Lucide (ISC). Кнопки имеют независимых владельцев касания; отпускание вне области, отмена, пауза и потеря фокуса сбрасывают ввод. В настройках можно выбрать кнопки вместо руля.

На компьютере — WASD/стрелки, пробел для ручника, R для сброса, C для камеры, G для гаража, H для сигнала, Esc для паузы. Сенсорные педали на компьютере скрыты. Обзор камеры — перетаскивание свободной части экрана; приближение — два пальца или колесо мыши. Три камеры: следящая, обзорная и салон.

Подвеска работает с шагом 120 Гц и интерполяцией кузова. Угол руля на скорости ограничивается кривизной траектории для приблизительно 0,95 g; внутреннее и внешнее передние колёса поворачиваются по геометрии Аккермана. Тяга уменьшается при пробуксовке, рабочие тормоза отпускают заблокированные колёса; ручник сохраняет возможность сорвать заднюю ось. Реальная траектория определяется PhysX, без принудительного разворота кузова или подмены скорости.

Скелет водителя закреплён в салоне, кисти ориентированы на обод, пальцы согнуты; IK следует за рулём. Четыре автомобиля, включая Tesla, получили художественно воссозданный салон. Это не скан заводского интерьера. На цифровой панели отображаются скорость и передача.

Все три графических режима имеют **цель 60 FPS**, а не подтверждённый результат на телефоне. Режим «Детали» включает более подробную Tesla, четыре каскада теней 4096, контактные тени SSAO, HDR, ACES и MSAA 4×. Разрешение адаптируется к времени кадра; низкий режим убирает дорогие эффекты. Измерения на настоящем iPhone ещё необходимы.

## Локальная сборка

Требуются активированная Unity 6000.3.26f1 с iOS Build Support и Xcode. На подготовленном Intel Mac установлен Xcode 15.4; окончательный архив для Apple собирается актуальным облачным Xcode.

```sh
python3 unity/Tools/check-source.py
bash unity/Tools/test-native.sh
bash unity/Tools/export-ios.sh
```

`export-ios.sh` собирает универсальный плагин для редактора, готовит URP и импорт, запускает Unity-тесты, делает реальные рендеры и только после успешных проверок экспортирует `unity/Build/iOS/Unity-iPhone.xcodeproj`. Логи и PNG находятся в `unity/artifacts` и не входят в Git.

Для локального архива с подходящим SDK и настроенной подписью доступен `archive-ipa.sh`. `verify-ipa.py` проверяет ARM64 Mach-O, UnityFramework, игровые данные, строгую подпись и совпадение сертификата с действующим профилем.

## Облачная сборка и подпись

Отдельная запись Apple: **Motor Coast**, App ID **6824150042**, bundle ID `app.zanderrroff.motorcoast`. Приложения Aloe и Mivori не менялись. Действующий сертификат распространения и профиль созданы для этой игры; закрытый ключ хранится вне репозитория на Mac владельца.

Первое подключение нового продукта Xcode Cloud требует настройки в Xcode. Подготовлен совместимый проект, а для сборки без этой ручной настройки используется GitHub Actions на `macos-26`. В Actions нет ключей подписи Apple. Облако создаёт неподписанный ARM64-архив; `sign-archive.py` подписывает его на Mac через временную изолированную связку ключей и проверяет результат.

```sh
python3 unity/Tools/prepare-xcode-cloud.py \
  --payload-url https://github.com/zanderrroff/tesla-roadster-drive/releases/download/ios-native-build-1/xcode-payload.tar.gz.enc
```

Скрипт создаёт зашифрованный пакет Unity-экспорта и небольшой проект `unity/Build/cloud-source` для ветки `ios-xcode-export`. Шифрование не позволяет публиковать исходники встроенного инструментария Unity открытым текстом. Пароль хранится локально вне Git и в отдельном секрете CI `MOTORCOAST_PAYLOAD_PASSWORD`. Перед распаковкой проверяются SHA-256 зашифрованного и исходного пакета. Пароль, ключи Apple и профили не включаются в игру.

Подписанная App Store IPA распространяется через TestFlight/App Store; ссылка на файл сама по себе не устанавливает её на произвольный iPhone.

После получения облачного архива:

```sh
python3 unity/Tools/sign-archive.py /path/to/MotorCoast.xcarchive
python3 unity/Tools/upload-testflight.py /path/to/MotorCoast.ipa \
  --key-id "$MOTORCOAST_API_KEY_ID" --issuer "$MOTORCOAST_API_ISSUER" \
  --private-keys-dir "$MOTORCOAST_API_KEYS_DIR"
```

Загрузка сначала проверяет структуру и подпись IPA, затем запускает проверку Apple. `--validate-only` выполняет проверки без отправки сборки. Успешная отправка не означает завершение обработки Apple; доступность в TestFlight проверяется отдельно. Логи сохраняются локально в `unity/artifacts`.
