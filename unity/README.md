# Motor Coast — Unity 6 / iPhone

Нативный перенос из браузерной игры в Unity **6000.3.26f1 LTS**, URP 17.3, Metal и IL2CPP. Игровая сцена, интерфейс, камеры и подвеска написаны на C#; нативный модуль C++ управляет тягой, торможением, ручником, безопасным реверсом и сглаживанием руля. При сборке iOS код C# также преобразуется в C++ через IL2CPP.

**Статус 18 октября 2026:** исходники переноса и ресурсы подготовлены. C++ проверен и скомпилирован для iPhone ARM64. Unity Editor, игра на устройстве, Xcode-архив, `.ipa` и TestFlight **ещё не проверены/не выпущены**. Unity отсутствует и не активирован; доступного места на текущем Mac недостаточно. Это не готовый релиз.

## Состав

- Семь машин: Tesla Roadster, BMW M3 E30, Mercedes AMG GT, Mercedes 190E EVO, Nissan Skyline C110, Porsche 911 Carrera 4S, Ferrari 458 Italia.
- Tesla: 133 574 треугольника в обычном режиме, 344 098 в режиме «Детали». Остальной парк — до 150 000 треугольников на машину.
- Импорт моделей выполняется редактором glTFast. В приложении нет загрузки моделей из интернета и декодирования Draco/WebP.
- Отдельные колёса и руль; управляемые руки водителя; родительская связь персонажа с шасси. Исходный сдвиг корневой кости сохранён через дополнительный объект-контейнер.
- WheelCollider/PhysX, шаг физики 120 Гц, интерполяция кузова и колёс, стабилизаторы, непрерывные столкновения, восстановление.
- Свободная площадка, дрифт-круги, трамплины, слалом, пит-павильон, побережье. Разметка не создаёт невидимых коллайдеров. Для рампы используется одна геометрия изображения и столкновения.
- Три камеры, вращение и приближение пальцами, мультитач, крупные педали, выбор свайпа руля или кнопок.
- Металлические/шероховатые материалы, текстуры асфальта Poly Haven, HDR-небо, отражение окружения, тени, ACES, умеренный Bloom.
- Режимы «Плавность», «Баланс», «Детали». Ограничение разрешения, адаптивное уменьшение render scale, ASTC 6×6 и mipmaps. 60/30 FPS — цели настроек, а не измеренные результаты.
- Звук электропривода для Tesla, запись двигателя для остальных машин, шины, ветер, столкновения и сигнал. Лицензии доступны в меню «Об игре».

## Сборка

1. Установить Unity Hub, войти в Unity и активировать подходящую лицензию. Для Unity Personal активация выполняется через Hub. Секреты и пароль не передавать в чат или репозиторий.
2. Установить Unity **6000.3.26f1** с **iOS Build Support**. Редактор и модуль занимают около 10,9 ГБ без кэшей; практически нужно минимум 20–25 ГБ свободного места для импорта и сборки.
3. Добавить в Hub каталог `unity/MotorCoast`. Для локального Apple-этапа задать `DEVELOPER_DIR`, не менять системный Xcode глобально.
4. Запустить из корня репозитория:

```sh
bash unity/Tools/test-native.sh
python3 unity/Tools/check-source.py
bash unity/Tools/export-ios.sh
```

`export-ios.sh` собирает плагин C++ для редактора, настраивает URP, импортирует ресурсы, запускает Unity EditMode-тесты и лишь после их успеха экспортирует `unity/Build/iOS/Unity-iPhone.xcodeproj`. Переменная `UNITY_EDITOR` позволяет указать другой путь к закреплённой версии редактора.

Для просмотра в редакторе: выполнить `bash unity/Tools/build-editor-plugin.sh`, затем меню **Motor Coast → 1. Prepare project**, открыть созданную сцену `Assets/Scenes/Coast.unity` и нажать Play.

Подпись использует отдельный Bundle ID **app.zanderrroff.motorcoast**, команду Apple **U8QHYG2G45** и версию **2.0.0**. Bundle ID пока записан только в конфигурации проекта; запись приложения и новый процесс Xcode Cloud ещё не созданы. Перед повторным экспортом задавать новый `BUILD_NUMBER`.

```sh
# Ключ читается из указанного файла, не копируется в проект.
export ASC_KEY_PATH='/путь/к/AuthKey_KEYID.p8'
export ASC_KEY_ID='KEYID'
export ASC_ISSUER_ID='ISSUER-UUID'
bash unity/Tools/archive-ipa.sh
```

Результат — `unity/artifacts/ipa/*.ipa`, только если Unity-экспорт, `xcodebuild archive`, подпись и export действительно завершились успешно. Скрипт проверяет наличие UnityFramework, игровых данных, подписи и provisioning profile. App Store/TestFlight IPA устанавливается через соответствующий канал Apple, не простым открытием ссылки на файл.

## Xcode Cloud — маршрут из сессии Aloe

Проверена сессия «Разработать Aloe для учета финансов». В ней использовались локальный Xcode 15.4 и облачный Xcode 26, автоматическая подпись и доставка в TestFlight. Доступ к App Store Connect и списку Xcode Cloud подтверждён для этого аккаунта. Существующие приложения Aloe/Mivori не менялись.

Для Unity есть дополнительный обязательный этап: лицензированный Unity Editor должен сначала создать проект Xcode. Xcode Cloud самостоятельно не преобразует C#-исходники Unity в игру.

После успешного экспорта:

1. Создать отдельную запись Motor Coast в App Store Connect.
2. Подготовить пакет для Apple, например:

```sh
python3 unity/Tools/prepare-xcode-cloud.py \
  --payload-url https://github.com/zanderrroff/tesla-roadster-drive/releases/download/ios-export-1/xcode-payload.tar.gz
```

3. Загрузить реальный `unity/artifacts/xcode-payload.tar.gz` в этот release; закоммитить содержимое `unity/Build/cloud-source` в отдельную ветку `ios-xcode-export`. Никакие крупные библиотеки Unity или ключи не помещать в Git. Скрипт `ci_post_clone.sh` скачивает пакет из этого репозитория и проверяет SHA-256.
4. Подключить эту ветку к **новому** workflow Xcode Cloud: проект `Unity-iPhone.xcodeproj`, схема `Unity-iPhone`, Xcode 26 или актуальный совместимый, Archive iOS, автоматическая подпись, Internal TestFlight.
5. Дождаться подписанного архива, скачиваемой IPA и успешной обработки TestFlight. До этого выпуск не считается завершённым.

Эти шаги облачной публикации пока не выполнялись: нет экспорта Unity. Подготовлены команды и проверяемый формат пакета.

## Проверки

Выполнены: C++ с AddressSanitizer/UndefinedBehaviorSanitizer; ARM64-компиляция с iOS SDK; контрольные суммы ресурсов; структура всех моделей; геометрия посадки и положение рук на исходных glTF; синтаксический разбор C#; синтаксис shell-скриптов. Подробности в `VERIFICATION.txt`.

Не выполнены: компиляция C# внутри Unity, импорт/рендер URP, Unity-тесты физики, тени/прозрачность на Metal, сенсорный ввод на телефоне, измерение FPS/нагрева/памяти, реальная подпись IPA. Тесты для Unity находятся в `Assets/Tests/Editor` и входят в обязательный экспортный процесс.

Перед релизом на реальном iPhone проверить: 10 минут свободного вождения; тормоз/реверс/ручник; все рампы; смену машин; камеру в салоне; поворот руля/кисти; отпускание пальца вне кнопки; два и три одновременных касания; фон/возврат; каждое качество. Зафиксировать модель iPhone, iOS, FPS, память и нагрев. Проверка синтаксиса не подтверждает эти свойства.
