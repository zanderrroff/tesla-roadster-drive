LIMITS / REMAINING DEVICE VALIDATION
- No physical iPhone run, sustained FPS, memory, heat or physical multitouch result.
  60 FPS is a target for Standard and Ultra, not a measured phone result.
  The editor preview is not an iPhone emulator or a device performance test.
- The GTA-level visual target is not achieved. Asset quality varies; the
  update does not guarantee every possible bug has been removed.
- Four interiors are artistic reconstructions, not factory interior scans.
  Other interiors are retained from their source models; detail varies.
- Ten maps are original layouts with licensed scenery and surface resources.
  They are not downloaded GTA cities. New territories are 2.4 x 2.4 km each.
- The photographic HDR sky and per-map sun are static; no dynamic weather.
- Character customization is character selection plus six clothing tints;
  it is not a face/body/wardrobe editor. Climbing covers reachable clear ledges
  up to 1.5 m, not arbitrary mountaineering or every real-world movement.
- Unity 6000.3 occasionally logs an editor-only Quick Search index exception;
  this exact editor trace is excluded from player-exception gating.
- First Xcode Cloud product onboarding requires Xcode UI. This build uses
  GitHub's macOS runner with current Xcode; signing stays local.
- External public TestFlight review and App Store release are not submitted.
  This is a native test build; an App Store-signed IPA cannot be installed
  on an arbitrary iPhone by downloading the file alone.

The published browser website is the earlier web version, not this native player.
